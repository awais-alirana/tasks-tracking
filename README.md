# TaskFlow - Task Management System

TaskFlow is a comprehensive task management system designed to streamline workflows with distinct views and functionalities for Team Leaders, Employees, and Managers.

## Features

- **Role-Based Access Control**: Separate secure login portals for Leaders, Employees, and Managers.
- **Task Management**: Assign, view, and track completion of tasks efficiently.
- **Employee Management**: Leaders can easily oversee and manage their team members.
- **Responsive UI**: A modern, clean, and responsive user interface built with Tailwind CSS and FontAwesome.

## Tech Stack

- **Frontend**: HTML5, CSS3, Tailwind CSS (via CDN)
- **Logic**: Vanilla JavaScript (ES6 Modules)
- **Icons**: FontAwesome 6

## Project Structure

- `index.html`: The main login page with role selection functionality.
- `leader.html`: The dashboard tailored for Team Leaders.
- `employee.html`: The dashboard for Employees to view and complete assigned tasks.
- `manager.html`: The dashboard for Managers to oversee broader operations.
- `assets/`: Contains styling (`assets/css/style.css`) and scripts (`assets/js/script.js`).

## Getting Started

1. Clone or download the project files to your local machine.
2. Open `index.html` in any modern web browser to access the application.
3. Select your appropriate role (Leader, Employee, or Manager) to log in and access your respective dashboard.
